# 투챙이(Toochangi) 투자 분석 에이전트 설계 및 진행 현황

이 문서는 투챙이 에이전트의 설계 방향, 기기 간 컨텍스트 동기화 방법, 그리고 현재까지 진행된 개발 현황을 기록합니다. 다른 기기(회사 컴퓨터, 모바일 등)의 AI 에이전트와 작업할 때 이 문서를 읽히면 이전 상태를 완벽하게 유지할 수 있습니다.

---

## 1. 핵심 아키텍처 및 디자인 의사결정

### 1.1 가챙이(가계부)와 투챙이(투자)의 통합 방향
*   **프론트엔드 대시보드 (통합):**
    *   가챙이(가계부)와 투챙이(투자 분석)는 **'개인 종합 자산 관리'** 대시보드로 통합하여 단일 정적 웹 브라우저 앱(HTML/CSS/JS) 형태로 구축합니다.
    *   사용자는 단 한 번의 Google OAuth 인증으로 가계부 시트와 투자 분석 기록 시트를 모두 조회할 수 있도록 설계합니다.
*   **백엔드/에이전트 로직 (모듈화 및 분리):**
    *   가챙이 에이전트(명세서/영수증 소비 분석)와 투챙이 에이전트(투자 보고서/기사 분석)는 서로 다른 파일 타입과 목적을 가지고 작동합니다.
    *   따라서 에이전트 실행 스크립트는 서로 독립된 모듈(독립된 구글 앱스 스크립트 또는 브라우저 실행 모듈)로 나누어 작성하여 유지보수성을 극대화합니다.

### 1.2 다중 기기(회사컴-집컴) 간 에이전트 대화 기억 보존 방안
*   **문제 상황:** IDE 에이전트의 대화 히스토리(`brain` 폴더 데이터)는 각 컴퓨터의 로컬 환경에 개별 저장되므로, 기기를 이동할 경우 이전 대화가 끊어지게 됩니다.
*   **해결 방안 (문서 기반 동기화):**
    *   의사결정 사항 및 진행 상황을 워크스페이스 내 문서 파일(`docs/toochangi_design.md`)에 수시로 기록하고 GitHub에 push합니다.
    *   다른 기기에서 개발을 이어나갈 때, 해당 컴퓨터의 AI 에이전트에게 **"프로젝트 내의 `docs/toochangi_design.md` 파일을 먼저 읽고 작업 계획을 세워줘"**라고 요청하여 컨텍스트를 즉시 100% 동기화합니다.

## 2. 투챙이 에이전트 개요 및 템플릿 정보

*   **동작 방식:** 구글 드라이브 내 특정 수집 폴더를 감시하여 새로운 투자 보고서/기사(텍스트, PDF 등)가 업로드되면 이를 읽어 Gemini AI로 분석합니다.
*   **분석 대상 항목 (JSON 포맷):**
    *   `summary`: 투자 보고서/기사 핵심 요약
    *   `stocks`: 분석과 관련된 주식 종목명
    *   `opinion`: 투자 의견 (매수 / 매도 / 관망 등)
    *   `duration`: 목표 투자 기간 (단기 / 중기 / 장기 등)
*   **결과 기록 및 아카이브:** 분석이 완료되면 구글 스프레드시트의 `"투자 기록"` 시트에 추가하고, 원본 보고서 파일은 드라이브 내 아카이브 폴더로 이동합니다.
*   **참조 템플릿:** [toochangi_template.js](file:///c:/Users/1988n/AgentMaker/templates/toochangi_template.js)
